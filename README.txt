STUDENT ATTENDANCE TRACKER — FRONTEND DEMO

Technology:
- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage/sessionStorage

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it with Chrome/Edge/Firefox.
4. On the login page, enter ANY non-empty User ID and Password.
   This is a dummy login; no real authentication or backend is connected.

FEATURES
- Dummy login and logout
- Dashboard with total, present, absent and attendance-rate statistics
- Daily attendance marking (Present / Absent)
- Select a date to view or edit that day's attendance
- Filter by All, Present, Absent and Unmarked
- Search students
- Add and delete students
- Export attendance as CSV
- Responsive layout for desktop and mobile
- Student and attendance data saved in browser localStorage

NOTES
- This is a frontend-only academic project/demo.
- Data is saved in the current browser on the current device.
- Clearing browser site data may remove saved records.
- Login accepts any non-empty ID and password and is NOT secure.
